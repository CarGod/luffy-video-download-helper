安装到 Agent

先开启服务，再复制安装说明，发给你要使用的本地 Agent。说明包含本机启动路径和配置，Agent 可以据此完成接入。

安装后，按 Agent 提示重新连接 MCP，再让它查看当前页面的视频。

助手未安装或连接失败？

运行安装包中的 Install-Luffy-Helper.command，重启浏览器后再点击「重新连接」。关闭服务会停止新的 Agent 调用，已开始的下载继续运行。

没有发现视频？

先在网页里播放视频，再点击「重新扫描」。分段视频需要从网络请求中发现，必要时刷新原网页并重新播放。

支持 MP4 / WebM 等直链与 HLS 点播（含普通 AES-128 加密）。纯扩展不支持 DRM、直播和 DASH；DASH 与大文件可交给本机助手。视频下载不设文件大小上限；浏览器内合并受可用内存和处理能力影响。
